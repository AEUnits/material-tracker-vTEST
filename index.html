WO Autocomplete - Custom Dropdown Test

This does NOT use the browser's native <datalist> / list="" attribute at all - no native suggestion popup can appear, so there's nothing to steal focus away from a Bluetooth keyboard. Everything below (the WO field, the dropdown, and the highlighting) is plain HTML/JS we fully control.

Try this: Type 20005577 below, hit Enter or tap elsewhere to save it to history, clear the field, then type 20005576 using a real/Bluetooth keyboard. With the old <datalist> approach, typing after the 6th matching digit could kick you out of the field on some phones. This version shouldn't do that, since the browser is never involved in the suggestion popup.
